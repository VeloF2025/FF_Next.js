### Pattern: Optional Context Hook

When a component needs to work both with and without a provider:

```typescript
// In provider file
export function useMyContext() {
  const context = useContext(MyContext);
  if (!context) throw new Error('Must be within Provider');
  return context;
}

export function useMyContextOptional() {
  return useContext(MyContext) ?? null;
}

// In component
const context = useMyContextOptional();
const value = props.value ?? context?.value ?? defaultValue;
```
