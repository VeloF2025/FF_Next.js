# FibreFlow Knowledge Base

Deep reference material for established patterns and architectural decisions.

## Structure

```
knowledge-base/
├── ui-patterns/          # UI/UX patterns and components
│   └── filter-aware-exports.md
├── rbac/                 # Role-Based Access Control
│   └── access-control-system.md
├── api-patterns/         # API design patterns (future)
└── architecture/         # System architecture decisions (future)
```

## When to Use

- **learnings.md** - Quick tips and gotchas discovered during development
- **knowledge-base/** - Detailed patterns with examples and rationale

## Adding New Entries

1. Choose or create appropriate subdirectory
2. Use descriptive filename (kebab-case)
3. Include: overview, implementation pattern, examples, pitfalls
4. Reference commit hash when pattern was established
