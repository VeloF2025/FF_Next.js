# Module: navigation.disabled

## Purpose
**DISABLED** - Legacy navigation system with context-based state management (replaced by `navigation` module).

## Status
This module is disabled and should not be used. It contains an older implementation of the navigation system that used React Context for state management.

## Key Differences from Active Module
- Uses `NavigationContext.tsx` for global state (removed in active version)
- Context-based tab state management vs. hook-based
- Similar registry and config structure otherwise

## Files
| File | Purpose |
|------|---------|
| `context/NavigationContext.tsx` | React Context provider for navigation state (LEGACY) |
| `config/registry.ts` | Module registry (same pattern as active module) |
| `components/ModuleTabs.tsx` | Tab components using context (LEGACY) |
| `hooks/useModuleTabs.ts` | Hook consuming NavigationContext (LEGACY) |

## Why Disabled
- Context caused unnecessary re-renders across unrelated modules
- Simpler hook-based approach in active `navigation` module
- Kept for reference during migration period

## Critical Rules
- **DO NOT** use this module for new features
- **DO NOT** import from `@/modules/navigation.disabled`
- Use `@/modules/navigation` instead
- Can be deleted after confirming no legacy references remain

## Migration Notes
If you find code importing from this module:
1. Update imports to use `/modules/navigation`
2. Remove `NavigationContext.Provider` wrapper if present
3. Replace context-based hooks with direct `useModuleTabs()` calls
