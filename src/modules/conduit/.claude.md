# Module: Conduit

## Purpose
Financial portfolio management for VelocityFibre projects. Tracks project economics
(revenue, costs, margins) across Prospective and Executable pipelines with inline-editable
tables and monthly forecast grids. Data sourced from Shareholder Model (SharePoint Excel).

## Critical Rules
- NEVER modify Shareholder Model source data — read-only via Graph API
- ALWAYS use `useConduitCalc` hook for derived calculations (margins, totals)
- Editable cells save per-project via PUT `/api/conduit/projects/[id]`

## Key Files
| File | Purpose |
|------|---------|
| `components/PortfolioTable.tsx` | Main portfolio grid — Prospective + Executable sections |
| `components/ProjectDetailPanel.tsx` | Expandable project drill-down with forecast |
| `components/MonthlyForecastGrid.tsx` | 60-month forecast grid per project |
| `components/conduit-cells.tsx` | Inline-editable cell components |
| `hooks/useConduitCalc.ts` | Derived calculations (margins, KPIs, totals) |
| `types/index.ts` | TypeScript interfaces for conduit data |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/conduit/projects` | List all portfolio projects |
| GET | `/api/conduit/projects/[id]` | Single project data |
| PUT | `/api/conduit/projects/[id]` | Update editable fields |
| GET | `/api/conduit/projects/[id]/detail` | Project financial detail |
