# Module: workflow
<!-- 50 lines max - Workflow engine and state management -->

## Purpose
Workflow engine for managing state transitions across installations, tickets, and other entities.

## Critical Rules
- NEVER skip workflow validation steps
- ALWAYS use WorkflowTemplateService for template operations
- NEVER modify workflow state directly - use transitions

| Term | Meaning |
|------|---------|
