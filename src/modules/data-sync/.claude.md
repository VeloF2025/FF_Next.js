# Module: data-sync

## Purpose
Unified data synchronization dashboard with grouped tabs for maintenance, activate, OLT reports, QField, and sync history.

## Key Files
| File | Purpose |
|------|---------|
| `components/DataSyncPage.tsx` | Main page with group navigation and RBAC filtering |
| `components/OverviewDashboard.tsx` | Dashboard showing stats across all sync groups |
| `components/groups/MaintenanceGroup.tsx` | Maintenance sync operations (QContact, weekly imports, WA tracking) |
| `components/groups/ActivateGroup.tsx` | Activate sync tabs (OES import, ARCH import, manual sync) |
| `components/groups/OltReportGroup.tsx` | OLT report management (import, pending, investigations) |
| `components/groups/QFieldGroup.tsx` | QField project management and sync |
| `components/groups/HistoryGroup.tsx` | Unified sync history timeline |
| `hooks/useSystemFeatures.ts` | Feature toggle hook for controlling tab visibility |
| `services/oltQueueProcessorService.ts` | OLT report queue processing |
| `services/oltAutoDetectService.ts` | OLT issue auto-detection logic |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/qfield-sync-dashboard` | QField sync dashboard stats |
| GET | `/api/qfield-sync-history` | QField sync history |
| POST | `/api/qfield-sync-start` | Start QField sync operation |
| GET | `/api/qfield-sync-current` | Current sync status |
| POST | `/api/qfield-sync-drops` | Sync drops to QField |
| POST | `/api/qfield-sync-poles` | Sync poles to QField |
| POST | `/api/qfield-sync-cables` | Sync cables to QField |
| GET | `/api/qfield.ts` | QField project operations |

## URL Structure
- `/system/data-sync` - Overview dashboard
- `/system/data-sync?group=maintenance` - Maintenance tabs
- `/system/data-sync?group=activate` - Activate tabs
- `/system/data-sync?group=olt` - OLT Report tabs
- `/system/data-sync?group=qfield` - QField tabs
- `/system/data-sync?group=history` - History timeline

## Access Control
- Tab groups filtered by RBAC permissions (`system.data-sync.*`)
- Individual tabs controlled by feature settings (Settings > System)
- Permission keys defined in `GROUP_PERMISSION_KEYS` constant

## Tab Groups
| Group | Permission Key | Description |
|-------|---------------|-------------|
| maintenance | `system.data-sync.maintenance` | QContact sync, weekly imports, WA tracking |
| activate | `system.data-sync.activate` | OES/ARCH import, manual sync |
| olt | `system.data-sync.olt` | OLT report processing and investigations |
| qfield | `system.data-sync.qfield` | QField project management |
| history | `system.data-sync.history` | Unified sync operation timeline |

## Critical Rules
- Always filter tabs by both RBAC permissions AND feature settings
- Use `useSystemFeatures()` hook to check feature toggles
- QField sync operations should be queued, not run synchronously
- OLT auto-detect runs on import to flag known issue patterns
