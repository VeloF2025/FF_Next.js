## Critical Rules
- Filter tabs by BOTH RBAC permissions AND feature settings (`useSystemFeatures()`)
- QField sync operations must be queued — never run synchronously
- OLT auto-detect runs on import to flag known issue patterns
- `scope_string` in `pon_stage_tracking` is **metres of stringing** — never label as count
- PON stage denominators: poles for build, joints for optical, drops for activation
- `pon_manual_overrides` must be LEFT JOIN — never INNER (lazy-insert table)
