- **Bug**: Multiple files had broken URL conversions between public and internal VF Storage URLs
- **Root cause**: nginx proxies `/storage/` → port 8091. Public URLs need `/storage/` prefix, internal URLs must NOT have it
- **Files fixed**: `documents-ocr-preview.ts`, `extract-id-photo.ts`, `pipelineDocumentSyncService.ts`, `storageAdapter.ts`, `dev-queue/attachments/route.ts`
- **Pattern**: Public = `https://vf.fibreflow.app/storage/{path}`, Internal = `http://100.96.203.105:8091/{path}`
- **Rule**: Always build URLs from `result.path`, never do naive domain replacement on `result.url`
