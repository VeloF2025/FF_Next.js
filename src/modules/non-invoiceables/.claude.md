## Issue Categories
| Category | Source | Trigger |
|----------|--------|---------|
| `pre_provision` | `oes_pp_data` | ONT pre-registered, not yet activated in OES |
| `serial_mismatch` | `offline_devices` / `olt_mismatch` | Serial doesn't match across systems |
| `offline` | `offline_devices` | Device not active or fiber break (note5) |
| `low_signal` | `offline_devices` | Signal below −26 dBm threshold (note1) |
| `degraded` | `offline_devices` | Signal degraded >2 dB vs link budget (note3) — monitor only |
| `missing_dr` | `ft_billing` | No DR photo submission on field app (note2) |

## Action Status Flow
`open` → `ticketed` → `in_progress` → `resolved` / `false_positive`

## Critical Rules
- This module replaces the old separate PP/Serial/OLT standalone tabs — do NOT re-add those
- `false_positive` means reviewed + confirmed not real — never auto-close these
- AI bulk ops must scope to NEW data only — never modify historic records
- Ticket creation via `CreateTicketModal` links the ticket back to the source issue
