# Dev Queue Module

**URL**: `/communications/dev-queue`
**Isolation**: Fully isolated (zero external dependencies)
**Last Updated**: 2026-01-20

## Overview

Kanban board for tracking feature requests and dev-queue items with voting, drag-drop, and attachments.


## API Routes (App Router)

| Route | Method | Purpose |
|-------|--------|---------|
| `/api/dev-queue` | GET | Get board with columns & items |
| `/api/dev-queue` | POST | Create new item |
| `/api/dev-queue/[id]` | GET | Get single item |
| `/api/dev-queue/[id]` | PUT | Update item (creator/admin only) |
| `/api/dev-queue/[id]` | DELETE | Delete item (creator/admin only) |
| `/api/dev-queue/move` | POST | Move item between columns |
| `/api/dev-queue/vote` | POST | Toggle vote on item |
| `/api/dev-queue/[id]/attachments` | GET/POST | Manage attachments |

## Database Tables (Neon PostgreSQL)

| Table | Purpose |
|-------|---------|
| `dev-queue_items` | Main items (title, description, status, priority, votes) |
| `dev-queue_columns` | Board columns (name, position, color, wip_limit) |
| `dev-queue_votes` | User votes (item_id, user_id, unique constraint) |
| `dev-queue_comments` | Discussion threads |
| `dev-queue_attachments` | File/URL attachments |

## Critical Rules

1. **NEVER** break isolation - this module has zero external FibreFlow dependencies
2. **ALWAYS** use `dev-queueService` singleton for API calls
3. **Status column is the Kanban column** - status field matches column name exactly
4. **Vote toggle** - clicking vote again removes the vote (unique constraint)
5. **Auth required** - all endpoints check `getAuth(req)?.userId`
6. **Permission check** - only creator or admin can edit/delete items
7. **Drag-drop admin only** - only admins can drag cards between columns
8. **Card click to edit** - clicking card opens edit modal (not drag)

## Common Operations

### Adding a new item
```typescript
const { createItem } = useDev Queue();
await createItem({ title, description, priority: 'medium' });
```

### Editing an item (click card)
```typescript
// Card click triggers onEdit callback
// AddDev QueueItemModal handles both create and edit
const { updateItem } = useDev Queue();
await updateItem(itemId, { title, description, priority });
```

### Moving between columns
```typescript
const { moveItem } = useDev Queue();
moveItem(itemId, targetColumn, position); // Called by DragDropContext.onDragEnd
```

### Voting
```typescript
const { voteItem } = useDev Queue();
await voteItem(itemId); // Toggles vote
```
