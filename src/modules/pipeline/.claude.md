# Pipeline Management Module

## Purpose
Track potential projects through approval stages (wayleave, municipal, traditional council) before they become planned projects.

## Status
✅ Phase 1-4 Complete - Full approval workflow, document management, alerts, and Smartsheet sync

## Key Types

### Project Types (`types/project.types.ts`)
- `PipelineProject` - Core project entity with status, location, client, financial estimates
- `PipelineStatus` - new | qualification | approvals_in_progress | approvals_complete | po_pending | ready_to_plan | planned | on_hold | cancelled | lost
- `ProjectType` - greenfield | brownfield | extension | upgrade
- `Priority` - low | medium | high | critical

### Approval Types (`types/approval.types.ts`)
- `PipelineProjectApproval` - Individual approval gate per project
- `ApprovalCategory` - wayleave | municipal | environmental | traditional | other
- `ApprovalStatus` - not_started | internal_review | submitted | under_review | approved | rejected | conditionally_approved | requires_amendment | resubmitted | expired | renewed | withdrawn
- `InternalApprovalStatus` - pending_pm | approved_pm | approved_ops | rejected (2-level internal approval)
- `PipelineApprovalDocument` - Document attached to approval with verification status

## Pipeline Status Flow
```
new → qualification → approvals_in_progress → approvals_complete → po_pending → ready_to_plan → planned
                                                                              ↓
                                                                     on_hold / cancelled / lost
```

## Approval Status Flow
```
not_started → internal_review → submitted → under_review → approved/rejected
                    ↓                            ↓
              conditionally_approved    requires_amendment → resubmitted
                                                               ↓
                                                         approved/rejected
```

## Internal Approval (2-level)
```
pending_pm → approved_pm → approved_ops → APPROVED (can submit externally)
    ↓             ↓              ↓
 rejected     rejected       rejected
```

## Key Features
1. **Approval Gates**: Visual progress through required approvals
2. **Expiry Tracking**: Automatic alerts at 90/30/7 days before expiry
3. **Internal Workflow**: 2-level approval (PM → Ops) before external submission
4. **Document Management**: Upload, verify, track documents per approval
5. **Follow-up Scheduling**: Track next follow-up dates with reminders
6. **Activity Logging**: Full audit trail of all actions
7. **Smartsheet Sync**: Bi-directional sync with Velocity_Master_Tracker

## Smartsheet Integration

### Configuration
Requires `SMARTSHEET_API_TOKEN` environment variable.

### Synced Sheet
- **Name**: Velocity_Master_Tracker
- **Sheet ID**: 8735086443712388
- **Direction**: from_smartsheet (imports to Neon)
