# Pipeline Module

## Purpose
Tracks potential fiber projects through the approval pipeline from initial qualification through wayleave/municipal/environmental approvals until PO (Purchase Order) is received.

## Status
Types-only module - contains type definitions for planned Pipeline feature.

## Key Types

### Project Types (`types/project.types.ts`)
- `PipelineProject` - Core project entity with status, location, client, financial estimates
- `PipelineStatus` - new | qualification | approvals_in_progress | approvals_complete | po_pending | ready_to_plan | planned | on_hold | cancelled | lost
- `ProjectType` - greenfield | brownfield | extension | upgrade
- `Priority` - low | medium | high | critical

### Approval Types (`types/approval.types.ts`)
- `PipelineProjectApproval` - Individual approval gate per project
- `ApprovalCategory` - wayleave | municipal | environmental | traditional | other
- `ApprovalStatus` - not_started | preparing | submitted | in_review | approved | rejected | expired
- `InternalApprovalStatus` - pending | pm_approved | ops_approved | rejected (2-level internal approval)
- `PipelineExpiryAlert` - Tracks expiry alerts at 90/30/7 days and expired

## Features (Planned)
1. **Project Pipeline** - Track projects from lead to PO
2. **Approval Tracking** - Multiple approval types per project
3. **Expiry Management** - Alert system for expiring approvals
4. **Smartsheet Sync** - Bi-directional sync with Smartsheet
5. **Document Management** - Upload/verify approval documents
6. **Follow-up Scheduling** - Track authority follow-ups

## Integration Points
- `clients` - Client relationships
- `staff` - Project manager, wayleaves officer assignments
- `projects` - Transition to planned project after PO received

## Database Tables (Planned)
- `pipeline_projects` - Core project data
- `pipeline_approval_types` - Approval type configuration
- `pipeline_project_approvals` - Project-specific approvals
- `pipeline_approval_documents` - Uploaded documents
- `pipeline_expiry_alerts` - Expiry alert tracking
