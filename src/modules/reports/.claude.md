## Purpose
Reports dashboard at `/reports`: activation uptake charts, ONT serial master export, weekly activations, and PDF report generation.

## Key Files
| File | Purpose |
|------|---------|
| `ReportsDashboard.tsx` | Main dashboard — stats grid + data exports + recent reports list |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/reports/ont-serials-export` | Excel: all ONT serials (OES + pre-provisions + field scans) |
| GET | `/api/reports/uptake` | Activation uptake data (live PONs only) |
| GET | `/api/reports/uptake-pdf` | PDF version of uptake report |
| GET | `/api/reports/weekly-activations` | Weekly activation counts |
| GET | `/api/reports/progress-today` | Today's activation progress |

## Critical Rules
- Activation reports are calculated on **live PONs only** (not all PONs)
- Revenue formula: `R3105 / 1.15` (excl. VAT) per live PON
- ONT serials export pulls from three sources: `oes_activations`, `oes_pp_data`, field scans
- Dashboard uses `useReportsDashboardData()` from `src/hooks/useDashboardData.ts`
- Export button triggers blob download — always check `Content-Disposition` header for filename

## Common Issues
| Issue | Fix |
|-------|-----|
| Uptake % inflated | Verify denominator is live PONs only, not total PONs |
| ONT export missing rows | Check all three source joins in `ont-serials-export.ts` |
| PDF generation fails | Check Puppeteer availability on server |
