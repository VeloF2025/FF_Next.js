# Wishlist Module

**URL**: `/communications/wishlist`
**Isolation**: Fully isolated (zero external dependencies)
**Last Updated**: 2026-01-20

## Overview

Kanban board for tracking feature requests and wishlist items with voting, drag-drop, and attachments.

## File Structure

```
src/modules/wishlist/
├── WishlistDashboard.tsx       # Main component (tabs: board, analytics, settings)
├── components/
│   ├── WishlistKanban.tsx      # Drag-drop board (@hello-pangea/dnd)
│   ├── WishlistColumn.tsx      # Single column with items
│   ├── WishlistCard.tsx        # Draggable item card
│   ├── WishlistAnalytics.tsx   # Stats dashboard
│   ├── AddWishlistItemModal.tsx # Create/edit items
│   └── AttachmentsModal.tsx    # View/add attachments
├── services/
│   └── wishlistService.ts      # API client (singleton)

```

## API Routes (App Router)

| Route | Method | Purpose |
|-------|--------|---------|
| `/api/wishlist` | GET | Get board with columns & items |
| `/api/wishlist` | POST | Create new item |
| `/api/wishlist/[id]` | GET | Get single item |
| `/api/wishlist/[id]` | PUT | Update item (creator/admin only) |
| `/api/wishlist/[id]` | DELETE | Delete item (creator/admin only) |
| `/api/wishlist/move` | POST | Move item between columns |
| `/api/wishlist/vote` | POST | Toggle vote on item |
| `/api/wishlist/[id]/attachments` | GET/POST | Manage attachments |

## Database Tables (Neon PostgreSQL)

| Table | Purpose |
|-------|---------|
| `wishlist_items` | Main items (title, description, status, priority, votes) |
| `wishlist_columns` | Board columns (name, position, color, wip_limit) |
| `wishlist_votes` | User votes (item_id, user_id, unique constraint) |
| `wishlist_comments` | Discussion threads |
| `wishlist_attachments` | File/URL attachments |

## Key Types

```typescript
type WishlistPriority = 'low' | 'medium' | 'high';

interface WishlistItem {
  id: string;

  description?: string;
  status: WishlistStatus;

  effort_estimate?: WishlistEffort;
  business_value?: number;  // 1-10
  votes: number;
  has_voted?: boolean;      // UI state from join
  comments_count?: number;
  attachments_count?: number;
  created_by?: string;
  created_by_name?: string;
}
```

## Critical Rules

1. **NEVER** break isolation - this module has zero external FibreFlow dependencies
2. **ALWAYS** use `wishlistService` singleton for API calls
3. **Status column is the Kanban column** - status field matches column name exactly
4. **Vote toggle** - clicking vote again removes the vote (unique constraint)
5. **Auth required** - all endpoints check `getAuth(req)?.userId`
6. **Permission check** - only creator or admin can edit/delete items

## Common Operations

### Adding a new item
```typescript
const { createItem } = useWishlist();
await createItem({ title, description, priority: 'medium' });
```

### Editing an item (click card)
```typescript
// Card click triggers onEdit callback
// AddWishlistItemModal handles both create and edit
const { updateItem } = useWishlist();
await updateItem(itemId, { title, description, priority });
```

### Moving between columns
```typescript
const { moveItem } = useWishlist();
moveItem(itemId, targetColumn, position); // Called by DragDropContext.onDragEnd
```

### Voting
```typescript
const { voteItem } = useWishlist();
await voteItem(itemId); // Toggles vote
```
