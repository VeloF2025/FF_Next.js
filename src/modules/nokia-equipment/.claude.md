# nokia-equipment module

Dashboard shell for Nokia ONT/network equipment management — import, track, and link Nokia Fibertime velocity data to SOW poles/drops and OneMap properties.

**Page:** `/nokia-equipment` → `pages/nokia-equipment.tsx` (SSR, no DB reads)
**API routes:** `pages/api/nokia/velocity.ts` — GET velocity records by `projectId` + optional `weekEnding`; derives `progress_status` (Completed/In Progress/Permission Granted/Surveyed/Pending) at query time; joins `sow_poles`, `sow_drops`, `onemap_properties`; POST is a stub (use import script)
**DB tables:**
- `nokia_velocity` — primary; UNIQUE on `(project_id, property_id, week_ending)`; key columns: `property_id`, `pole_number`, `drop_number`, `ont_barcode`, `installation_date`, `pole_permission_date/status/agent`, `home_signup_*`, `sales_*`, `last_modified_date`, `week_ending DATE`, `raw_data JSONB`
- `nokia_equipment` — generic catalogue (UUID PK, `equipment_id`, `serial_number` UNIQUE, `model_number`, `equipment_type`, `status`, `project_id`, JSONB cols for vlan/network_ports/metrics); created by `scripts/create-field-tables.ts`, not yet wired to UI
**Key files:**
- `NokiaEquipmentDashboard.tsx` — nav-card shell only; stats are hardcoded placeholders; sub-routes (`/nokia-equipment/catalog`, `/inventory`, `/installations`, `/maintenance`, `/import`, `/reports`) do not exist
- `scripts/import-nokia-velocity.js` — one-shot XLSX importer; reads "1Map Field App" sheet, expects header starting with "Property ID"; hardcoded to project louissep15 (`e2a61399-...`)
- `scripts/analyze-nokia-linking.js` — standalone analysis of pole/drop/onemap match rates against `nokia_velocity`
- `scripts/verify-nokia-status.js` — checks table existence and reports import stats
**Gotchas:**
- Velocity API still uses the **Neon serverless shim** (`neon()`), not `pg.Pool`; conditional SQL fragments will break here
- Dashboard sub-routes are dead links — no sub-pages exist; module is largely a scaffold
- `progress_status` is computed at query time from `installation_date`, `ont_barcode`, `pole_permission_date`; not stored in DB
- RBAC key is `field.nokia-equipment`; visible to field/manager/admin roles (migration 221)
- `nokia_velocity` data is also consumed by the SOW ImportsDataGrid (`/sow` module) via the same `/api/nokia/velocity` endpoint
