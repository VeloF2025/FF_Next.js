# billing module

## Purpose
Weekly FT (Fibre Time) billing reconciliation for Finance. Parses uploaded Excel bundles (zone uptake + FT payment summary + GRV), reconciles against DB projects, and surfaces deductions, lifecycle status, and zone uptake data for the Finance team.

## Key Files
| File | Role |
|------|------|
| `components/BillingUploadTab.tsx` | Upload UI — folder drop for weekly bundle (xlsx files) |
| `components/WeeklySummaryTab.tsx` | Weekly summary table — reconciled rows per project |
| `components/DRPaymentStatusTab.tsx` | DR payment status view |
| `services/bundleProcessor.ts` | Orchestrates parsing of all bundle files |
| `services/parseFTPaymentSummary.ts` | Parses FT payment summary Excel sheet |
| `services/parseZoneUptake.ts` | Parses zone uptake Excel sheet |
| `services/resolveProjectName.ts` | Fuzzy project name → DB project_id resolver |

## API Endpoints
| Route | Method | Purpose |
|-------|--------|---------|
| `/api/billing/upload-weekly-bundle` | POST | Upload full weekly bundle (folder drop) |
| `/api/billing/upload-weekly` | POST | Upload single weekly file |
| `/api/billing/weekly` | GET | Fetch weekly billing summary |
| `/api/billing/reconcile` | POST | Trigger reconciliation run |
| `/api/billing/projects` | GET | List projects eligible for billing |
| `/api/billing/dr-history` | GET | DR payment history |
| `/api/billing/status` | GET | Overall billing status |

## Access Control
- Finance tab group is **restricted to super_admin only** (PR #871)
- Regular admins and managers cannot see the Finance menu item

## Critical Rules
- Bundle upload expects: FT payment summary + zone uptake + GRV — all three files
- Project name resolution uses fuzzy matching via `resolveProjectName.ts` — ambiguous names are flagged, not silently matched
- Partial imports are allowed; blocked projects are surfaced inline (not a hard failure)
- All environments share the same production DB — billing changes are immediate

## Domain Notes
- FT = Fibre Time (billing system used by ISP partners)
- GRV = Goods Received Voucher (confirms delivery for billing)
- Zone uptake = % of homes in a zone that are activated (affects deduction calculation)
- Deductions applied when zone uptake < contracted threshold
- See `memory/ft-billing-reconciliation.md` for full domain logic
