# Module: maintenance
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Maintenance ticket system with QContact integration, team assignment, escalation workflows, verification tracking, and photo attachments.

## Critical Rules
- NEVER bypass escalation rules for overdue tickets
- ALWAYS sync with QContact for external tickets
- Check QA readiness before closing tickets
- **Storage: Use VF Storage API (port 8091) via `vfStorageAdapter`**

## QContact Sync (Feb 2026)
- **Bidirectional sync**: Inbound (QContact→FF) + Outbound (FF→QContact)
- **Status sync**: Works via `updateCase()` PATCH → maps FF status to QC status
- **Note sync**: Velocity account gets **403** on Note/Conversation/Event creation
  - Fallback: appends note text to case `description` field via PATCH
  - `description` persists but is NOT visible in QContact activity timeline
  - Proper fix: ask FiberTime to grant Note creation permission
- **Custom fields**: `c__update`, `c__feedback`, `c__test_field` are dropdowns (reject free text)
- **Auth**: Token auto-refresh via password on 401; 30s cooldown between auth attempts
- Sync logs: `maintenance_qcontact_sync_log` table
