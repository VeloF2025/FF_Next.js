# Health & Safety Module

## Overview

Comprehensive H&S management for fibre installation projects, including:
- **Project H&S**: Site-specific safety audits and configuration
- **Contractor H&S**: Organization-level compliance with gate checking
- **Incident Management**: Uses maintenance ticketing system (not separate)
- **SA Compliance**: OHS Act, Construction Regulations, SANS standards

## Key Concepts

### Two Types of H&S

1. **Project H&S** (`hs_project_config`, `hs_project_audits`)
   - Site-specific safety requirements
   - Configurable audit frequency (daily/weekly/monthly)
   - 8 checklist categories with SA regulation references
   - Special work permits (heights, hot work, confined space)

2. **Contractor H&S** (`hs_contractor_compliance`, `hs_contractor_documents`)
   - Organization-level compliance
   - Document management (policies, insurance, certificates)
   - **Gate checking** - hard block for project assignment

### Scoring System

- **0-100%** score with **RAG mapping**:
  - Red: <50%
  - Amber: 50-79%
  - Green: ≥80%

- **Weighted calculation** (contractors):
  - Documents: 25%
  - Incidents: 30% (starts at 100, decreases)
  - Training: 15%
  - Corrective Actions: 15%
  - Audits: 15%

### Gate Checking (Hard Block)

Contractors MUST pass gate before project assignment:
- Required docs: `safety_policy`, `liability_insurance`, `safety_plan`
- No major/fatal incidents in 12 months
- Overall score ≥50%
- Training compliance ≥70%

```typescript
import { checkContractorGate } from '@/modules/health-safety';

const result = await checkContractorGate(contractorId);
if (!result.can_assign) {
  // Show blockers to user
  console.log(result.blockers);
}
```

### Incident Management (Uses Maintenance Tickets)

H&S incidents are **maintenance tickets** with extended fields:

```typescript
// Ticket types added to maintenance module:
TicketType.HSE_INCIDENT   // Injuries, property damage
TicketType.HSE_NEAR_MISS  // Near misses

// H&S-specific fields in hs_ticket_details table:
- hs_incident_type: injury | near_miss | property_damage | environmental | vehicle
- hs_severity: minor | moderate | major | fatal
- witness_names, root_cause, investigation fields
- DoL reporting fields (SA requirement)
```

## Checklist Categories

8 SA-compliant categories:

1. **Working at Heights** - Construction Reg 8
2. **PPE Compliance** - OHS Act s8(2)(d)
3. **Scaffolding Safety** - SANS 10085
4. **Electrical Safety** - Electrical Installation Reg
5. **First Aid Readiness** - General Safety Reg 3
6. **Fire Safety** - Construction Reg 29
7. **Fibre-Specific** - Industry best practice (laser, glass, chemicals)
8. **Site Conditions** - Construction Reg 24-26

## Usage Examples

### Check Gate Before Assignment
```typescript
import { checkContractorGate } from '@/modules/health-safety';

const gate = await checkContractorGate(contractorId);
if (!gate.can_assign) {
  throw new Error(`Cannot assign: ${gate.blockers.join(', ')}`);
}
```

### Calculate Contractor Score
```typescript
import { calculateContractorHSScore } from '@/modules/health-safety';

const result = calculateContractorHSScore({
  contractor_id: 123,
  document_compliance: { total: 5, valid: 4, expired: 1, pending: 0 },
  incidents: { minor: 2, moderate: 0, major: 0, fatal: 0 },
  training_records: { total: 10, current: 8, expired: 2 },
  corrective_actions: { total: 3, completed: 2, overdue: 1, in_progress: 0 },
  last_audit_score: 85,
});

console.log(result.overall_score); // e.g., 78
console.log(result.rag_status);    // 'amber'
console.log(result.gate_approved); // true/false
```

## Common Patterns

### Document Upload Flow
1. User uploads document → Firebase Storage
2. Create `hs_contractor_documents` record (status: pending)
3. Admin verifies → status: valid/rejected
4. On expiry → status: expired (auto-updated)
5. Gate check includes document validation

### Audit Flow
1. Select project → Create `hs_project_audits` (status: in_progress)
2. Go through checklist → Create `hs_audit_responses`
3. Failed items → Option to create maintenance ticket
4. Complete audit → Calculate score, update status
5. Score affects project H&S dashboard

### Incident Flow
1. Create maintenance ticket (type: hse_incident)
2. Create `hs_ticket_details` with H&S fields
3. Ticket workflow: OPEN → ASSIGNED → IN_PROGRESS
4. Investigation completed → Update hs_ticket_details
5. Ticket closed → Affects contractor incident score
