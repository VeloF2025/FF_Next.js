## Purpose
Two parallel action item systems: (1) generic `action_items` linked to any source; (2) `manco_action_items` specifically for Board/MANCO strategic meeting decisions, with Kanban, strategic grid, and AI extraction.

## Database Tables
- `action_items` — generic items (title, description, assignee, due_date, status, source_type, source_id, priority)
- `manco_action_items` — MANCO strategic items (extended fields for strategic context)
- `manco_action_item_comments` — comment threads
- `manco_action_item_meetings` — meeting linkage (many-to-many)

## Critical Rules
- NEVER hard-delete completed items — use status=`cancelled` or `completed`
- ALWAYS link to source: `source_type` + `source_id` (meeting_id, project_id, etc.)
- Two distinct services: `actionItemsService` (generic) vs `manco-action-items` API routes
- MANCO items have comment threads — load lazily in `MancoDetailPane`
- AI extraction via `/extract` uses Teams meeting transcript text as input
