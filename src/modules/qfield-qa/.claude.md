# QField QA Module

## Purpose
Photo validation and QA workflow for QField-synced field photos. Provides AI-powered validation using VLM (Vision Language Model) and human QA review workflow with assignments, escalation, and manual overrides.

## Key Files

### Components
- `components/QFieldQaDashboard.tsx` - Hybrid layout: sidebar (project + hierarchy) + photo grid
- `components/ProjectSelector.tsx` - Project dropdown for sidebar
- `components/HierarchyTree.tsx` - Activate-style tree: Zone → PON → Individual Pole/Joint
- `components/SearchFilterBar.tsx` - Search + status/priority filters + breadcrumb
- `components/PhotoListTab.tsx` - Photo grid with filters, bulk actions, badges
- `components/PhotoDetailModal.tsx` - Full photo view + AI results + actions

### Hooks & Services
- `hooks/useQFieldQa.ts` - Data fetching, hierarchy navigation, actions, auto-refresh
- `services/qfieldQaApiService.ts` - API client for all QA endpoints

### Types
- `types/index.ts` - PhotoValidation, QAStats, QAHierarchy*, WorkflowStatus, etc.

## API Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/qfield/qa-hierarchy` | GET | Zone → PON → feature tree with photo counts |
| `/api/qfield/qa-validations` | GET | List photos with filters, pagination |
| `/api/qfield/qa-validate` | POST | Trigger VLM validation (single or bulk) |
| `/api/qfield/qa-actions` | POST | Approve/reject/escalate photos |
| `/api/qfield/qa-assignments` | POST | Assign photos to reviewers |
| `/api/qfield/qa-stats` | GET | Dashboard statistics |
| `/api/qfield/photo-proxy` | GET | Proxy photos from MinIO |

## Hierarchy Navigation

Drill-down: **Project → Zone → PON → Individual Pole/Joint → Photos**

### Zone/PON Data Source
Zone and PON data comes from the `drops` table (NOT `poles`). The `poles` table has NULL zone_no/pon_no for QField projects.

```sql
-- Use DISTINCT ON subquery to avoid inflated counts from multiple drops per pole
LEFT JOIN (
  SELECT DISTINCT ON (pole_number) pole_number, zone_no, pon_no
  FROM drops ORDER BY pole_number, zone_no, pon_no
) dz ON v.feature_id = dz.pole_number
```

### Hierarchy Filter Params
- `zoneNo` - filter by zone (-1 = NULL/unassigned)
- `ponNo` - filter by PON (-1 = NULL/unassigned)
- `featureType` - filter by work_type
- `featureId` - filter by individual pole/joint ID

## Database Tables
- `qfield_photo_validations` - Main table with photo_key, vlm results, workflow status
- `qfield_validation_config` - VLM prompts and thresholds per work type
- `drops` - Source for zone_no/pon_no (joined via pole_number = feature_id)

## Critical Rules

### Logger Format (Pino)
```typescript
// CORRECT - data object first, then message
log.info({ module: 'qfield-qa-validate', photoKey, count }, 'Processing validation');
log.error({ module: 'qfield-qa-validate', error: err.message }, 'Validation failed');

// WRONG - this logs incorrectly!
log.info('qfield-qa-validate', { data }, 'message');
```

### MinIO Photo Path Format
Photos are stored with version suffixes:
```
projects/{project_id}/files/DCIM/{filename}.jpg/{version-id}
```
Example: `projects/137eb5ec-.../files/DCIM/JPEG_20251016130535337.jpg/v20251107044855-6296d2d1`

### Badge Visibility
Use solid backgrounds for badges overlaid on photos:
```typescript
// GOOD - visible on any background
className="bg-yellow-500 text-white shadow-lg"

// BAD - invisible on matching backgrounds
className="bg-yellow-500/20 text-yellow-400"
```

## VLM Integration
- Endpoint: `http://100.96.203.105:8100/v1/chat/completions`
- Model: `Qwen/Qwen3-VL-8B-Instruct`
- Fetches photos via Docker: `docker exec qfieldcloud-minio-1 mc cat 'local/bucket/path'`
- Returns JSON: `{valid, confidence, issues[], feedback}`

## Workflow States
- `pending` - Awaiting QA review
- `in_review` - Assigned to reviewer
- `approved` - QA passed
- `rejected` - Needs retake
- `escalated` - Needs supervisor review

## Common Issues

### AI validation triggers but never completes
- Check logger format (see Critical Rules above)
- Check VLM service: `curl http://100.96.203.105:8100/v1/chat/completions`
- Check MinIO path includes version suffix

### Badges invisible on photos
- Use solid colors, not semi-transparent
- Add `shadow-lg` for depth
