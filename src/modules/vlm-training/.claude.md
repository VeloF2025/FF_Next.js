# Module: vlm-training
<!-- VLM training dataset management for Fibertime home install photos -->

## Purpose
Manages the curated dataset of Fibertime home-install drops used to train/evaluate the VLM (Qwen3-VL). Provides browse, filter, exclusion (HITL kill switch), region summary, and PDF report generation.

## Key Files
| File | Purpose |
|------|---------|
| `services/trainingDataService.ts` | DB queries: list, get, region summary, exclude drop |
| `services/__tests__/trainingDataService.test.ts` | Unit tests for service layer |

## API Endpoints
| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/vlm-training/list` | Paginated list with region/minSteps/activeOnly/excludedOnly filters |
| GET | `/api/vlm-training/[dropNumber]` | Single drop detail + photos metadata |
| PATCH | `/api/vlm-training/[dropNumber]` | Exclude drop from training (requires auth + role) |
| GET | `/api/vlm-training/report` | HTML/PDF report grouped by region |

## Database Tables
- `vlm_training_dataset` — snapshot of qualifying Fibertime drops: drop_number, region, installer_name, core_steps_present, dome_steps_present, steps_present (JSONB), photos_metadata (JSONB), excluded_from_training, excluded_reason, excluded_by, excluded_at

## Data Shape
- `core_steps_present` — count of mandatory install steps with photos
- `dome_steps_present` — count of dome/closure steps with photos
- `photos_metadata` — array of `{ step, field, filename, url, attachmentId }`
- Source: Fibertime home installs from 1Map (NOT VF infrastructure projects)

## Critical Rules
- Dataset is from **Fibertime home installs via 1Map** — not VF QField/SOW projects
- Max 100 drops per region (capped during ingest) — check region counts before bulk import
- Exclusion is soft-delete only (`excluded_from_training = true`) — rows are never deleted
- `excluded_by` stores the staff email of who triggered the HITL exclusion
- Uses `pg.Pool` via `@/lib/db-pool` (NOT Neon shim)
- Auth required on all endpoints; exclusion requires specific role

## Common Issues
| Issue | Fix |
|-------|-----|
| Region cap exceeded | Query `SELECT region, COUNT(*) FROM vlm_training_dataset GROUP BY region` before import |
| Excluded drop reappears | Exclusion is flag-based; check `excluded_from_training = false` filter in list query |
