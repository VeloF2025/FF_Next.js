# Module: help-center

## Purpose
Complete help center with searchable manual content, table of contents navigation, and markdown rendering.

## Key Files
| File | Purpose |
|------|---------|
| `HelpCenterPage.tsx` | Main page with sidebar TOC, search, and content display |
| `components/TableOfContents.tsx` | Interactive sidebar navigation tree |
| `components/SearchBar.tsx` | Full-text search with highlighting |
| `components/SectionRenderer.tsx` | Renders section content with support for text/markdown/video |
| `components/MarkdownRenderer.tsx` | Markdown to HTML with syntax highlighting |
| `components/ChatWidget.tsx` | Chat interface component (if enabled) |
| `data/manual-content.ts` | Static manual content structure and data |
| `hooks/useHelpCenter.ts` | State management for navigation, search, and breadcrumbs |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/help-center/manual` | Fetch manual content (static data) |

## Features
- **Table of Contents**: Collapsible sidebar with nested sections
- **Search**: Full-text search across all manual content with result highlighting
- **Markdown Support**: Rich text formatting, code blocks, tables, images
- **Navigation**: Prev/next buttons, breadcrumbs, section jumping
- **Responsive**: Mobile-friendly with hamburger menu
- **Export**: Download section as PDF/markdown (if implemented)

## Content Structure
Content defined in `data/manual-content.ts`:
```typescript
{
  sections: [
    {
      id: string,
      title: string,
      icon: LucideIcon,
      subsections: [
        {
          id: string,
          title: string,
          content: string | markdown,
          type: 'text' | 'markdown' | 'video'
        }
      ]
    }
  ]
}
```

## Critical Rules
- Use `stripMarkdown()` helper for search result previews (removes formatting)
- Content is static — stored in `manual-content.ts`, not database
- `SectionRenderer` handles images: `![alt](src)` inline + `<img>` block-level
- `MarkdownRenderer` does NOT handle images (only used for chat/search contexts)
- Search highlights use `<mark>` tags — sanitize user input
- Mobile: sidebar auto-closes after navigation

## Recent Changes (Feb 2026)

### AI Chat Assistant (Phases 1-3)
- **Phase 1** (`becbd939`): Help Center foundation with pgvector extension for RAG
- **Phase 2** (`00d09c43`): AI chat interface with three tools:
  - `search_knowledge`: Semantic search using pgvector embeddings
  - `query_database`: Read-only SQL queries for data lookups
  - `get_schema`: Database schema exploration
- **Phase 3** (`8a7440fe`): Production hardening with rate limiting (10 req/min per user)

### Knowledge Ingestion Pipeline
- **Script**: `scripts/ingest-knowledge.js` — Processes markdown docs into chunked embeddings
- **Embedding model**: OpenAI `text-embedding-3-small` (1536 dimensions)
- **Chunking**: 800 tokens per chunk with overlap for context preservation
- **Storage**: `help_center_knowledge` table with pgvector `vector(1536)` column

### RBAC Integration
- **Permission**: `communications.chat-data-lookups` — Required for AI assistant to query database
- **Seed script**: `scripts/seed-help-center-permissions.js` — Grants permission to admin/super_admin roles
- **Enforcement**: Chat API checks permission before executing `query_database` tool

### QContact Integration
- **Bidirectional sync** (`35da23cb`): Help Center ↔ QContact with status precedence rules
- **Status mapping**: Draft → Open, Published → Resolved, Archived → Closed

### User Manual Updates
- **v1.4**: Added Field App Portal and Mission Control sections
- **Screenshots**: 34 PNG images in `/help-center/screenshots/`
- **Coverage**: Login, dashboards, Pipeline, Activate, Fleet, Procurement, Reports

### Rate Limiting
- **Implementation** (`3faf6a6d`): 10 requests per minute per user for chat endpoints
- **Storage**: In-memory cache with sliding window algorithm
- **Response**: 429 status with retry-after header
