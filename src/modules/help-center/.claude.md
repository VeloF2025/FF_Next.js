# Module: help-center

## Purpose
Complete help center with searchable manual content, table of contents navigation, and markdown rendering.

## Key Files
| File | Purpose |
|------|---------|
| `HelpCenterPage.tsx` | Main page with sidebar TOC, search, and content display |
| `components/TableOfContents.tsx` | Interactive sidebar navigation tree |
| `components/SearchBar.tsx` | Full-text search with highlighting |
| `components/SectionRenderer.tsx` | Renders section content with support for text/markdown/video |
| `components/MarkdownRenderer.tsx` | Markdown to HTML with syntax highlighting |
| `components/ChatWidget.tsx` | Chat interface component (if enabled) |
| `data/manual-content.ts` | Static manual content structure and data |
| `hooks/useHelpCenter.ts` | State management for navigation, search, and breadcrumbs |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/help-center/manual` | Fetch manual content (static data) |

## Features
- **Table of Contents**: Collapsible sidebar with nested sections
- **Search**: Full-text search across all manual content with result highlighting
- **Markdown Support**: Rich text formatting, code blocks, tables, images
- **Navigation**: Prev/next buttons, breadcrumbs, section jumping
- **Responsive**: Mobile-friendly with hamburger menu
- **Export**: Download section as PDF/markdown (if implemented)

## Content Structure
Content defined in `data/manual-content.ts`:
```typescript
{
  sections: [
    {
      id: string,
      title: string,
      icon: LucideIcon,
      subsections: [
        {
          id: string,
          title: string,
          content: string | markdown,
          type: 'text' | 'markdown' | 'video'
        }
      ]
    }
  ]
}
```

## Critical Rules
- Use `stripMarkdown()` helper for search result previews (removes formatting)
- Content is static - stored in `manual-content.ts`, not database
- Search highlights use `<mark>` tags - sanitize user input
- Mobile: sidebar auto-closes after navigation
