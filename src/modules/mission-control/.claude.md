## Purpose
Monitors autonomous agents, live message feeds, task board, and system health by proxying to a separate Mission Control backend service.

## Key Files
| File | Purpose |
|------|---------|
| `MissionControlDashboard.tsx` | Main dashboard; 4 tabs: Dashboard, Live Feed, Agents, Task Board |
| `hooks/useMissionControl.ts` | Polling hook — dashboard 10s, live-feed 3s (active tab only) |
| `types.ts` | `MCAgent`, `MCTask`, `MCMessage`, `MCDashboard`, `MCSystemHealth` |
| `components/DashboardTab.tsx` | Stats + agent status cards + system health overview |

| `components/AgentsTab.tsx` | Detailed agent cards (status, capabilities, last active) |
| `components/TaskBoardTab.tsx` | Kanban: pending → in-progress → completed |
| `components/SystemHealthPanel.tsx` | Memory, disk, load avg, service port checks |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/mission-control/dashboard` | All dashboard data (proxied) |
| GET | `/api/mission-control/messages?limit=50` | Recent agent messages |
| POST | `/api/mission-control/tasks` | Create task |
| PATCH | `/api/mission-control/tasks/{id}` | Update task |
| DELETE | `/api/mission-control/tasks/{id}` | Delete task |

All routes proxy through `pages/api/mission-control/[...path].ts` → `http://127.0.0.1:3847/api`.
