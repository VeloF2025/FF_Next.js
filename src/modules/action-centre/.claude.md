# Module: action-centre
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Unified billing-reconciliation dashboard that classifies FT deduction rows (N1-N5 notes), tracks 1Map serial fixes, raises NOC tickets, and surfaces automation rule-engine runs.

## Critical Rules
- ALWAYS call `classifyReconRow()` (pure function) before writing any dispute/fix bucket — single source of truth per RFC 2026-04-17 §5
- NEVER use conditional SQL fragments via the Neon shim — use explicit query branches
- Routes use `withAuth()` only — no fine-grained `withPermission()` guard. Add one if you need RBAC scoping
