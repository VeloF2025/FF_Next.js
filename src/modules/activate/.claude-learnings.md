## 2026-02-25: apiResponse.success() Double-Wrapping Bug

**Problem**: PP Data tab showed blank stats (Total Imported, Activated, Located, etc. all empty, Last Import: "Never").

**Root cause**: Commit `2c1fe6ba` (API Error Std Phase 1 Batch 6) changed `res.status(200).json(...)` → `apiResponse.success(res, ...)` but left the inner `{ success: true, data: { ... } }` structure intact. Since `apiResponse.success()` already wraps in `{ success: true, data: ... }`, this caused double-nesting.

**Before refactor** (working): `res.json({ success: true, data: { total: 5 } })` → client gets `{ success: true, data: { total: 5 } }`
**After refactor** (broken): `apiResponse.success(res, { success: true, data: { total: 5 } })` → client gets `{ success: true, data: { success: true, data: { total: 5 } } }`

**Fix**: Remove inner `{ success: true, data: ... }` wrapper. Pass payload directly to `apiResponse.success()`.

**Affected files fixed**: `import-pp-data.ts` (stats, list, lookup-status), `pp-data-tickets.ts`
**Additional bug**: `pp-data-tickets.ts` line 113 referenced `error` instead of `err` (catch variable name mismatch)
