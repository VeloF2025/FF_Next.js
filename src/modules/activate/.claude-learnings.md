## 2026-01-22: Staging 500 Error - Port Conflict

**Issue:** `/api/activate/drops` returning 500 on staging (vf.fibreflow.app)

**Root Cause:** Port 3006 was held by a stale process, preventing `fibreflow.service` from starting properly. The service kept restarting but couldn't bind to port.

**Diagnosis:**
```bash
# Check service logs - showed EADDRINUSE error
sudo journalctl -u fibreflow.service -n 100
# Error: listen EADDRINUSE: address already in use :::3006
```

**Fix:**
```bash
ssh velo@100.96.203.105
echo 'velo2026' | sudo -S fuser -k 3006/tcp
echo 'velo2026' | sudo -S systemctl restart fibreflow.service
```

**Prevention:** Add to staging health check or pre-deploy script to kill stale processes.
