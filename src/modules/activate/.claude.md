## Purpose
DR photo review with VLM AI categorization, 5-phase QA wizard, and WhatsApp integration.

## Critical Rules
- NEVER bypass VLM health check before categorization
- ALWAYS validate prerequisites before Phase 2 (photo review)
- ALWAYS use `qaAutoFailService.getTechnicianIssues()` for WA feedback (not internal QA issues)
- NEVER send VLM comparison results to technicians (internal only)

## Key Files
| File | Purpose |

| `components/wizard/QaWizardContainer.tsx` | 5-phase wizard orchestration |

## Common Issues
| Issue | Fix |
|-------|-----|
| VLM timeout | Resize images <1024px before sending |
| Photos not categorizing | Check OneMap fetch first, verify photo URLs |
| Swap not detected | Check `looksLikeOntSerial()` patterns in qaAutoFailService |
