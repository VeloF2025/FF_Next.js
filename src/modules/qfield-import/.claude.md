# Module: QField Import

## Purpose
Multi-phase wizard for importing GeoPackage (GPKG) data from QFieldCloud projects into FibreFlow database. Supports layer selection, preview scanning, merge/replace modes, and detailed import job tracking.

## Architecture

### Flow
```
User selects QField project
    ↓
/api/qfield/gpkg-preview (read_gpkg.py --preview)
    ↓
Preview: Layer counts + sample fields shown
    ↓
User selects layers + import mode (merge/replace)
    ↓
/api/qfield/gpkg-import (read_gpkg.py --project-id)
    ↓
Python reads GPKG features from MinIO
    ↓
importPoles/Joints/etc (UNNEST bulk upsert)
    ↓
qfield_import_jobs updated with results
```

### Tech Stack
- **Frontend**: React hooks (useQFieldImport), TypeScript, Lucide icons
- **Backend**: Next.js API routes, Neon PostgreSQL, child_process exec
- **Data Source**: QFieldCloud MinIO (docker exec)
- **Python**: read_gpkg.py (WKB geometry decoding, layer auto-detection)

## API Endpoints

| Method | Endpoint | Purpose | Input | Output |
|--------|----------|---------|-------|--------|
| `GET` | `/api/qfield/gpkg-layers?qfieldProjectId=<uuid>` | List GPKG files in MinIO | qfieldProjectId (query) | `{ files: GpkgFile[] }` |
| `POST` | `/api/qfield/gpkg-preview` | Get layer counts + sample fields | `{ qfieldProjectId }` | `{ layers: Record<LayerType, LayerPreview> }` |

## Backend Implementation

### Python Reader (`read_gpkg.py`)
**Location**: `scripts/qfield-sync/read_gpkg.py`
- Runs locally via `child_process.exec` in Next.js API
- Reads GPKG from MinIO: `docker exec qfieldcloud-minio-1 mc ls qfieldcloud-prod/projects/{projectId}/files/`
- Decodes WKB binary geometry with envelope handling
- Auto-detects layer types by column heuristics
- Filters coordinates by South Africa bounds (22°S–35°S, 16°E–33°E)
- Output: JSON with `layers: { [name]: { count, features: [...], sample_fields } }`
- **Modes**: `--preview` (fast: metadata only) or full feature read

### Import Functions (`src/lib/qfield/gpkg-import-layers.ts`)
- Pattern: Batch UNNEST 1000 features per query (prevents memory explosion)
- **Replace mode**: `DELETE FROM <table> WHERE project_id = ?` then bulk INSERT
- **Merge mode**: `ON CONFLICT (project_id, unique_key) DO UPDATE` with COALESCE (preserve existing non-null)
- **Source tracking**: Sets source='qfield' or 'sow+qfield' for audit
- Returns: `{ created: number, updated: number, errors: string[] }`
- Exported: `importPoles()`, `importJoints()`, `importCableSpans()`, `importDrops()`, `importZoneBoundaries()`, `importPonBoundaries()`, `importPops()`

### Job Tracking (`qfield_import_jobs` table)
```sql
CREATE TABLE qfield_import_jobs (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL,
  qfield_project_id UUID NOT NULL,
  status VARCHAR(50), -- 'running', 'completed', 'completed_with_errors', 'failed'
  layer_counts JSONB, -- { [layer]: { created, updated, errors } }
  records_created INTEGER,
  records_updated INTEGER,
  errors JSONB,
  started_at TIMESTAMP,
  completed_at TIMESTAMP
);
```

## Critical Rules

### State Machine
- **Strict phases**: select → preview → importing → complete
- **Reset clears all**: Phase, preview, selectedLayers, importResult, errors
- **Auto-select**: All layers with count > 0 auto-selected after preview fetch
- **Phase-aware errors**: Banner persists; clears on phase change

### Import Modes
- **Merge**: `COALESCE(existing_field, new_field)` — existing non-null data preserved, new data fills gaps
- **Replace**: DELETE all layer data for project, then INSERT fresh — full refresh
- **Source field**: Tracks 'qfield', 'sow', 'sow+qfield' for audit trail

### Validation & Error Handling
- **UUID validation**: Both projectId and qfieldProjectId must match UUID regex
- **Layer validation**: selectedLayers array non-empty; all items in VALID_LAYERS
- **Mode validation**: Must be 'merge' or 'replace' exactly
- **Timeout**: 120s for import, 60s for preview (bash exec timeout)
- **Parse errors**: If Python stdout not valid JSON, return 500 "Failed to parse GPKG reader output"
- **Stderr handling**: Python warnings logged but don't fail if stdout OK

### Performance
- **Batch size**: 1000 features per UNNEST query
- **Preview fast path**: `--preview` flag avoids full feature parsing
- **Credentials required**: `credentials: 'include'` in all fetch calls (cookie auth)
- **Buffer limits**: 50MB for import, 10MB for layers/preview

### Database Constraints
- **Unique keys enforced**: (project_id, pole_number), (project_id, joint_id), etc.
- **Source tracking**: ON CONFLICT updates source to 'sow+qfield' if was 'sow'
- **Geometry**: WKB-decoded; NULL allowed for points outside SA bounds

## Common Patterns

### Adding a New Layer
1. Add to `LayerType` union in `types/index.ts`
2. Add LAYER_CONFIG entry in `LayerPreviewCard.tsx` (icon + label)
3. Add LAYER_LABELS entry in `ImportProgressBar.tsx`
4. Create `importNewLayer()` function in `gpkg-import-layers.ts`
5. Add case in `importLayer()` dispatcher in `gpkg-import.ts`
6. Add layer to Python reader's layer detection (column heuristics)
7. Run migration for new table

### Debugging Import Failures
**Check these in order:**
1. Python stderr: `docker logs qfieldcloud-minio-1` or server logs
2. MinIO access: `docker exec qfieldcloud-minio-1 mc ls local/qfieldcloud-prod/projects/<id>/files/`
3. Unique key conflicts: `SELECT COUNT(*) FROM poles WHERE project_id = <id> AND source = 'qfield'`
4. South Africa bounds: Some coordinates filtered by read_gpkg.py
5. Job record: Check `qfield_import_jobs` for status, layer_counts, errors

### Fetching Linked QField Projects
- API: `GET /api/qfield/projects?projectId=<uuid>`
- Returns list of linked projects (from projects table qfield_project_id field)
- Multiple QField projects per FibreFlow project allowed (dropdown UI)

## Troubleshooting

### "Failed to parse GPKG reader output"
- Python script crashed or output non-JSON
- Check server stderr logs for traceback
- Verify qfieldProjectId exists in MinIO

### Timeout on large datasets
- Normal for 10k+ features
- Try breaking into smaller imports
- Increase timeout in API config if needed

### "No data found for layer"
- Layer not detected in GPKG file
- Check Python layer heuristics match your field names
- Verify GPKG structure matches expected schema

### Merge mode not updating fields
- COALESCE(existing, new) only fills NULL
- If field already has value, it won't be replaced
- Use Replace mode for full refresh
