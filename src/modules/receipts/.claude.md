# Module: receipts
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Staff expense-receipt capture (camera-only PWA), VLM OCR extraction (vendor/total/VAT/date/category), per-staff submission workflow at /my/receipts, and finance review/export at /staff/receipts.

## Critical Rules
- NEVER allow file-upload fallback — receipt capture MUST trigger live camera (`capture="environment"`) per feedback_camera_only_pwa; no `<input type="file">` without capture attribute
- ALWAYS pre-generate the receipt UUID before upload so the image filename and DB row share the same `id` — `insertReceipt()` requires `args.id`
- NEVER allow staff to edit a receipt once status transitions out of `submitted` — `updateOwnSubmittedReceipt()` enforces `AND status = 'submitted'` and returns null on locked rows

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/my/receipts/index` | Staff's own non-rejected receipts |
| POST | `/api/my/receipts/save` | Save captured receipt (insert + image upload) |
| POST | `/api/my/receipts/extract` | VLM OCR extraction for a captured image |
| PATCH | `/api/my/receipts/[id]/edit` | Staff edits own submitted receipt |
| GET | `/api/my/receipts/[id]/download` | Secure image download scoped to session staff |
| GET/POST | `/api/staff/receipts` | Finance receipt listing |
| POST | `/api/staff/receipts-review` | Approve/reject receipt |
| GET | `/api/staff/receipts-export` | CSV export for finance |
| GET | `/api/staff/receipts-image` | Admin image proxy |

## Database Tables
- `staff_receipts` - One row per captured receipt; `status` drives the workflow (`submitted → approved/rejected/reconciled`)

## Dependencies
- **External:** Qwen3-VL VLM on `:8100` (OCR), VF Storage (image storage)
- **Internal:** `@/lib/db-pool`, `categories.ts` (closed taxonomy), `@/lib/logger`

## Common Tasks
| Task | Pattern |
|------|---------|
| Add a new category | Extend `RECEIPT_CATEGORIES` in `categories.ts` + update `RECEIPT_PROMPT` in `extraction.ts` |
| Finance approve receipt | POST `/api/staff/receipts-review` with `{ id, action: 'approved', note }` |
