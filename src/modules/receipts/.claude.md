# Module: receipts
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Staff expense-receipt capture (camera-only PWA), VLM OCR extraction (vendor/total/VAT/date/category), per-staff submission at `/my/receipts`, finance review/export at `/staff/receipts`.

## Critical Rules
- NEVER allow file-upload fallback — receipt capture MUST trigger live camera (`capture="environment"`); no `<input type="file">` without it
- ALWAYS pre-generate the receipt UUID before upload so image filename and DB row share the same `id` — `insertReceipt()` requires `args.id`
- NEVER allow staff to edit once status leaves `submitted` — `updateOwnSubmittedReceipt()` enforces `AND status = 'submitted'`
