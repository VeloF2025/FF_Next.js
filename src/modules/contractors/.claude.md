# Module: contractors
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Contractor lifecycle management: onboarding stages, document upload/verification, team assignment, project linkage, invoice/progress-claim/payment tracking, and RAG compliance scoring.

## Critical Rules
- NEVER approve contractor documents without the `contractors.verify` permission check — use `withPermission()` guard on all verify endpoints
- ALWAYS use LOWER() for email lookups on the `contractors` table — contractor emails are not case-normalised at ingestion
- NEVER delete a contractor with linked projects — `contractors-delete.ts` already blocks on a `contractor_projects` count check; do not weaken that guard
