# Staff Documents Module

Document management for staff compliance — upload, OCR extraction, verification, and audit trail.

## Purpose
Manage staff identity and compliance documents (SA ID, passport, driver's license, certifications, medical certificates, police clearance, etc.) with OCR extraction and verification workflows.

## API Routes
- `pages/api/staff-documents-upload.ts` — Upload with magic byte validation, OCR, VF Storage
- `pages/api/staff-documents-download.ts` — Download/view from VF Storage
- `pages/api/staff-documents/[documentId]/verify.ts` — Document verification

## Storage
VF Storage API (100.96.203.105:8091) — files stored under staff document paths.

## Database Tables
- `staff_documents` — Document records with OCR metadata, expiry dates, status
- `staff` — Staff member profiles
- `staff_projects` — Project assignments

## Features
- Multi-file upload (e.g. driver's license front+back)
- OCR extraction with metadata storage
- Document verification workflow
- Audit logging (upload/download events)
- Expiry date tracking
- Arcjet protection (bot detection, rate limiting)
