# Module: procurement
<!-- 50 lines max - BOQ, RFQ, PO, Stock management -->

## Purpose
Procurement workflow management: Bill of Quantities (BOQ), Request for Quotes (RFQ), Purchase Orders (PO), and stock tracking.

## Critical Rules
- NEVER modify prices without HITL confirmation
- ALWAYS validate stock levels before creating PO
- ALWAYS link RFQ items to BOQ line items

| File | Purpose |

| `services/rfq/rfqCrud.ts` | RFQ CRUD operations |

## API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/procurement/boq` | List BOQs |
| POST | `/api/procurement/boq` | Create BOQ |
| GET | `/api/procurement/rfq` | List RFQs |
| POST | `/api/procurement/rfq/{id}/convert-to-po` | Convert RFQ to PO |

## Database
- `boq` - Bill of Quantities
- `boq_items` - BOQ line items
- `rfq` - Request for Quotes
- `rfq_items` - RFQ line items
- `purchase_orders` - Purchase orders
- `stock_items` - Inventory

## Workflow
```
BOQ → RFQ → Quotes → PO → GRN → Stock
```

## Common Issues
| Issue | Fix |
|-------|-----|
| RFQ not loading items | Check BOQ link, verify `boq_id` FK |
| Stock mismatch | Run stock reconciliation |
