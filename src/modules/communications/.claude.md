# Module: communications
<!-- 50 lines max - includes WhatsApp admin portal -->

## Purpose
Communication management including WhatsApp admin portal for groups, templates, logs, and service management.

## Critical Rules
- NEVER restart WhatsApp services without checking session validity first
- ALWAYS use `servicesApi.pairingStatus()` before initiating new pairing
- NEVER expose sensitive config values (is_sensitive=true) in responses
