# QField Module

Umbrella module for QField GIS integration. Core logic lives in `qfield-sync/`, `qfield-import/`, and `qfield-qa/`.

## Purpose
Bidirectional sync between QFieldCloud GIS app and FibreFlow — field data collection (poles, drops, cables), QA validation, and GPKG import/export.

## API Routes (30 endpoints)
- `pages/api/qfield.ts` — Health, job management, worker control
- `pages/api/qfield-sync-*.ts` — Sync operations (drops, cables, poles, dashboard)
- `pages/api/qfield/*.ts` — Projects, QA, GPKG import/preview, OES sync, poles, photo proxy
- `pages/api/activate/trigger-qfield-sync.ts` — Trigger from Activate
- `pages/api/construction-qa/ingest-qfield.ts` — QA ingestion

## Related Modules
- `src/modules/qfield-sync/` — Core sync services (has own `.claude.md`)
- `src/modules/qfield-import/` — GPKG import pipeline
- `src/modules/qfield-qa/` — QA validation workflows

## Key Services
- `qfield-sync/services/qfieldSyncService.ts` — Main sync logic
- `qfield-sync/services/qfieldcloudApiService.ts` — QFieldCloud API client
