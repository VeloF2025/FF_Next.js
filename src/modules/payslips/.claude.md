# Module: payslips
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
HR payslip import (Sage/VIP/Isaflow CSV + PDF matching), per-staff secure download at /my/payslips, bulk batch upload for HR admins, and 5-year retention archiving.

## Critical Rules
- ALWAYS project DATE columns with `to_char(col, 'YYYY-MM-DD')` — pg midnight UTC shifts the day in SAST (IDOR guard depends on this being correct)
- NEVER pass `staffIdScope = null` to `findPayslipById()` from a staff-facing route — null scope is admin-only and bypasses ownership checks
- ALWAYS upsert via `upsertPayslip()` (not raw INSERT) — the ON CONFLICT clause preserves `archived_at` so re-imports don't un-archive aged-out rows

## Database Tables
- `payslips` - One row per staff per pay period; `archived_at` used for soft-retention (>5y)
