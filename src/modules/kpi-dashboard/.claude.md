# Module: kpi-dashboard
<!-- Executive KPI + enhanced analytics dashboard with charts and leaderboards -->

## Purpose
Two-component KPI dashboard: a legacy stat-card view (`KPIDashboard`) and an enhanced real-time analytics view (`EnhancedKPIDashboard`) with trend charts, team leaderboard, and QA funnel.

## Key Files
| File | Purpose |
|------|---------|
| `KPIDashboard.tsx` | Legacy stat cards (hardcoded % values for project/team/timeline/quality) |
| `EnhancedKPIDashboard.tsx` | Real-time dashboard: trend chart, leaderboard, funnel, project comparison |
| `@/hooks/useDashboardData.ts` + `useKPIDashboardData()` | Specialized hook, loads stats + trends in parallel |
| `@/services/dashboard/dashboardStatsService.ts` | Calls `analyticsApi` for stats and trends |
| `@/services/api/analyticsApi.ts` | API client for all `/api/analytics/` endpoints |
| `@/config/dashboards/dashboardConfigs.ts` | `getKPIDashboardCards()` — maps stats → card configs |
| `@/components/ui/charts.tsx` | `TrendChart`, `FunnelChart`, `GaugeChart` |

## API Endpoints (via analyticsApi)
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/analytics/dashboard/stats` | Core KPI stats |
| GET | `/api/analytics/dashboard/summary` | Summary metrics |
| GET | `/api/analytics/dashboard/trends` | Trend data points |
| GET | `/api/analytics/kpis` | KPI list with values |
| POST | `/api/analytics/kpis/calculate` | Recalculate KPIs |
| GET | `/api/analytics/kpis/targets` | KPI targets |
| GET | `/api/analytics/projects/trends` | Project trend data |
| GET | `/api/analytics/projects/performance` | Per-project performance |

## Critical Rules
- `KPIDashboard.tsx` legacy cards have hardcoded % values — not from DB; `EnhancedKPIDashboard.tsx` is the live version
- `useKPIDashboardData()` loads stats + trends in parallel via `Promise.all` — errors are caught per-call
- Date range filters (`from`, `to`, `groupBy`) must be consistent across all analytics queries
- `EnhancedKPIDashboard` uses `createLogger('EnhancedKPIDashboard')` — check named logger on errors
