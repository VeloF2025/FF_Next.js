## Database Tables
- `pon_stage_tracking` — per-PON build stage progress (source for Dashboard + Build + PON tabs)
- `pon_manual_overrides` — PM-editable overrides; lazy-insert table
- `master_tracker` — financial tracker rows; `project_id` is TEXT not UUID

## Critical Rules
- `pon_manual_overrides` is lazy-insert — **always LEFT JOIN**, never INNER JOIN
- `master_tracker.project_id` is TEXT — cast with `::uuid` when joining to `projects`
- `scope_string` = **metres of stringing** — display as "String (m)", never as a count
- PM blockage display: show `pm_blockage ?? auto_blockage`
- Stage denominators: poles for build stage, joints for optical, drops for activation
- Falls back to poles count for optical stage when joints lack `pon_no`

## Common Issues
| Issue | Fix |
|-------|-----|
| Override data missing | Check LEFT JOIN — INNER JOIN silently drops un-overridden PONs |
| `master_tracker` join error | Cast `project_id::uuid` at join boundary |
| Optical % wrong | Verify joints have `pon_no` populated; fallback uses poles |
| PON stage not updating | Check `pon_stage_tracking` sync cron in data-sync module |
