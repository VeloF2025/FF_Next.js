# tracker module

## Purpose
Consolidated project tracker at `/tracker` — four tabs:
1. **Dashboard** — cross-project KPI overview (pon_stage_tracking aggregates)
2. **Build Tracker** — per-project PON-level build progress from pon_stage_tracking
3. **Financial Tracker** — per-project pole/contractor rows from master_tracker (AG Grid)
4. **Settings** — dropdown value management

## Data Sources
| Layer | Table | Notes |
|-------|-------|-------|
| Dashboard | `pon_stage_tracking` + `projects` | Aggregated, no project selector |
| Build Tracker | `pon_stage_tracking` LEFT JOIN `pon_manual_overrides` | Overrides are lazy-insert — LEFT JOIN mandatory |
| Financial Tracker | `master_tracker` | project_id is TEXT not UUID — cast at join boundaries |

## Key Files
| File | Role |
|------|------|
| `app/(main)/tracker/page.tsx` | Tab router + project selector |
| `components/DashboardPage.tsx` | Cross-project KPI table |
| `components/BuildTrackerPage.tsx` | PON-level build progress with PM blockage editing |
| `components/MasterTrackerPage.tsx` | Financial tracker wrapper (AG Grid) |
| `components/MasterTrackerTable.tsx` | AG Grid table — 39 columns, zone_no/hld_pon pinned |
| `components/TrackerSelectListAdmin.tsx` | Dropdown value management |
| `types.ts` | `PonRow`, `BuildRow`, `MasterRow` types |

## API Endpoints
| Route | Method | Purpose |
|-------|--------|---------|
| `/api/tracker/dashboard` | GET | Cross-project KPI aggregates |
| `/api/tracker/build/[projectId]` | GET | pon_stage_tracking + pon_manual_overrides LEFT JOIN |
| `/api/tracker/build/[projectId]/overrides` | PATCH | Upsert pon_manual_overrides (PM editable fields) |
| `/api/tracker/master/[projectId]` | GET/POST | master_tracker rows |
| `/api/tracker/export/pon/[projectId]` | GET | Excel export from pon_stage_tracking |

## Critical Rules
- `pon_manual_overrides` is lazy-insert — **always LEFT JOIN**, never INNER JOIN
- `master_tracker.project_id` is TEXT (not UUID) — cast with `::uuid` when joining to `projects`
- `scope_string` = metres of stringing — never label as a count, display as "String (m)"
- PM blockage overrides take priority: display `pm_blockage ?? auto_blockage`
