# Module: attendance
<!-- Keep under 50 lines - reference, don't duplicate -->

## Purpose
Staff time-and-attendance system covering clock-in/out (geofenced + selfie), corrections workflow, weekly lock/unlock, bulk export, Cartrack GPS cross-verification, and the /my portal auth layer.

## Critical Rules
- NEVER project DATE columns without `to_char(col, 'YYYY-MM-DD')` — pg returns JS Date at server-local midnight which JSON-shifts a day in SAST
- ALWAYS gate correction approvals through the `attendance_adjustments` status machine (`pending → approved/rejected`) — never update `attendance_entries` directly from a staff-facing route
- NEVER remove or re-order geofence checks in `portal/geofenceUtils.ts` — geofence is the legal record of presence

## Database Tables
- `attendance_entries` - Clock-in/out records (primary fact table)
- `attendance_adjustments` - Correction requests (status machine)
- `attendance_weekly_locks` - Period lock records
- `attendance_daily_summaries` - Pre-aggregated daily totals
- `attendance_credentials` - /my portal login credentials
- `attendance_auth_sessions` - /my portal JWT sessions
- `attendance_exceptions` - Flag records (late, absent, missing clock-out)
- `attendance_gps_verifications` - Cartrack cross-check log
- `attendance_bulk_action_audit` - Bulk lock/unlock audit trail
- `public_holidays` - SA public holiday calendar
