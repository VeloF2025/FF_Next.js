# Module: navigation
<!-- Centralized module registry, tab routing, and RBAC-gated visibility for all modules -->

## Purpose
Centralized navigation system: module registry, dynamic tab routing with sub-tabs, and permission-based tab visibility.

## Registry Functions
| Function | Purpose |
|----------|---------|
| `registerModuleConfig(config)` | Register a module's nav config |
| `getModuleConfig(moduleId)` | Get by module ID |
| `getAllModuleConfigs()` | Get all registered modules |
| `getModuleConfigByPath(path)` | Find module by URL path (handles trailing slashes, query params) |
| `getActiveTabByPath(moduleId, path)` | Get active tab for a URL |

## Usage Pattern
```typescript
import { useModuleTabs } from '@/modules/navigation/hooks';
const { moduleConfig, currentTab, isActive } = useModuleTabs('noc');
```

## Critical Rules
- All module configs must be imported and registered in `config/index.ts`
- Tab `path` values must match Next.js page routes exactly
- Use `getModuleConfigByPath()` for route matching — handles trailing slashes and query params
- Default tab redirects are handled by page components, not this module
- Tabs with `rbacKey` must be filtered in UI based on RBAC before rendering
- `ModuleTabs` = top-level module nav; `SubTabs` = secondary within-module tabs
