### Theme Storage
- **Key:** `fibreflow-theme-preference`
- **Format:** `{ theme: ThemeName, useSystemTheme: boolean, lastChanged: Date }`
- **Location:** localStorage

### Theme Application Flow
1. **SSR:** `<html class="dark">` rendered by default
2. **Blocking Script:** Reads localStorage, applies correct class before paint
3. **ThemeContext:** Takes over after hydration, manages state
4. **CSS Variables:** Applied via `--ff-*` custom properties

### FOUC Prevention
**Critical:** Both `pages/_document.tsx` and `app/layout.tsx` contain inline blocking scripts that:
1. Read `fibreflow-theme-preference` from localStorage
2. Apply `dark` class to `<html>` element
3. Set `color-scheme` CSS property
4. Set inline `background-color` on `<body>`

See `src/components/layout/.claude.md` for full implementation details.

## Common Issues

| Issue | Cause | Fix |
|-------|-------|-----|
| Theme flash on navigation | Script missing in router | Add to both `_document.tsx` and `app/layout.tsx` |
| Wrong default theme | localStorage has old value | Clear localStorage or migrate in loadThemePreference |
| Form controls light in dark mode | Missing `color-scheme` | Add `document.documentElement.style.colorScheme = 'dark'` |
