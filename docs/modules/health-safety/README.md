# Health & Safety Module

## Purpose
The Health & Safety Module manages health and safety compliance for fibre installation projects. It ensures adherence to safety regulations and standards throughout the project lifecycle.

## Key Features
- **Dashboard**: Overview of compliance status and safety statistics
- **Incidents**: Recording and tracking of safety incidents with severity levels, corrective actions, attachments, and documentation
- **Checklists**: Safety inspection checklists for audit and verification
- **Project H&S**: Site-specific safety audits, audit frequency configuration, and checklist categories
- **Contractor H&S**: Contractor compliance verification, document management, and gate checking to prevent non-compliant assignments

## Key Files & Structure
- `src/modules/health-safety/components/` — UI components for dashboards, incidents, and checklists
- `src/modules/health-safety/services/` — Business logic and data management
- `src/modules/health-safety/constants/` — Safety categories and compliance rules
- `src/modules/health-safety/types/` — TypeScript type definitions
- `src/modules/health-safety/index.ts` — Module exports
