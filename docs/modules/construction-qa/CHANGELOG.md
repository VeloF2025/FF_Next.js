## [2026-03-13] Automated Photo Sync & QField Feedback Loop

### Added

#### ✨ GPKG Photo Extraction Pipeline (Commit: bdf8ea0)
- **New Script:** `scripts/extract-gpkg-photos.py` (507 lines)
  - Automatically extracts photo references from QFieldCloud GeoPackage files
  - Detects 8-step construction checklist columns using pattern matching
  - Maps checklist steps (1-8) to photo assignments
  - Performs version resolution for MinIO storage keys
  - Supports 7 QField projects (Lawley, Mohadin, Mamelodi, Etwatwa, Thembisa POP 1, Thembisa POP 3, Tonga)
  - Dry-run mode for testing without database writes
  - Force reprocessing with `--force` flag
  - Batch resolution of previously-unversioned storage keys (738 photos fixed)

- **New Script:** `scripts/cron-qa-ingest.sh` (56 lines)
  - Orchestrates daily photo ingestion workflow
  - Scheduled: 05:00 SAST (03:00 UTC) daily
  - Runs GPKG extraction before QField ingestion
  - Supports both QField and SharePoint ingestion sources
  - Graceful error handling (continues if GPKG extraction fails)

- **Database Migration:** `231_qfield_photo_validations_checklist_step.sql`
  - Added `checklist_step` column (INT) to `qfield_photo_validations`
  - Added `step_label` column (TEXT) to `qfield_photo_validations`
  - Created `qfield_gpkg_sync_state` table to track GPKG version processing

- **Service Enhancement:** `qfieldIngestionService.ts`
  - Propagates `checklist_step` and `step_label` from intermediate table to final photos
  - Added logic to update civil step booleans on reviews:
    - `civil_step_01_before_photo` ← checklist_step = 1
    - `civil_step_02_during_photo` ← checklist_step = 2
    - `civil_step_03_depth_photo` ← checklist_step = 3
    - `civil_step_04_end_plates` ← checklist_step = 4
    - `civil_step_05_compaction` ← checklist_step = 5
    - `civil_step_06_level_check` ← checklist_step = 6
    - `civil_step_07_after_photo` ← checklist_step = 7
    - `civil_step_08_signature` ← checklist_step = 8
  - Automatically updates `construction_qa_photos` with step metadata

- **Project Mapping:** Added Tonga to QFIELD_TO_FIBREFLOW
  - QField: `7fe59cdc-b1d5-475d-8448-5cf2e9f7175b`
  - FibreFlow: `ce3bf310-d6ba-4ede-ab36-a8c902a5efc6`

#### ✨ QA Decision Workflow & Auto-Generated Notes (Commit: 4a96b85)
- **New API Endpoint:** `POST /api/construction-qa/push-qfield-comment` (344 lines)
  - Pushes QA decision notes back to QFieldCloud GPKG
  - Writes to "Q/A Civil Comments" column in GPKG table
  - Allows technicians to see feedback directly in QField mobile app
  - Resolves feature IDs to GPKG fid automatically
  - Creates delta payloads with status and date updates
  - Handles async execution (non-blocking from final-decision endpoint)

- **Feature:** Auto-Generated QA Notes (`PhaseFinalDecision.tsx`)
  - Automatically generates note template when user selects reason codes
  - Template format: `[DECISION]: N issue(s) found.\n- Issue 1\n- Issue 2`
  - User can still manually edit notes before submission
  - Tracked via `notesAutoGenerated` ref to avoid overwriting user edits

- **Service Enhancement:** `final-decision.ts`
  - Triggers async push-qfield-comment after REWORK_NEEDED or FAIL decision
  - Uses fire-and-forget pattern (doesn't block API response)
  - Returns `qfieldPushed` status in response
  - Logs warnings if push fails, but doesn't fail the QA decision

- **Photo Proxy Improvement:** `photo-proxy.ts` (Enhanced)
  - Added dynamic version resolution for unversioned MinIO keys
  - Implements `resolveLatestVersion()` function
  - Tries latest version first, then falls back to unversioned path
  - Gracefully handles paths without `/v2` suffix
  - Better error messages for debugging

- **Batch Unversioned Key Fix:** `extract-gpkg-photos.py`
  - Added `resolve_unversioned_keys()` function
  - Runs automatically at end of extraction pipeline
  - Batch-fixed 738 photos with unversioned MinIO paths
  - Updates both `qfield_photo_validations` and `construction_qa_photos`

## Detection Patterns (Reference)

### Civil Construction Steps (GPKG Column Names)
Pattern matching is case-insensitive.

| Step | Regex Pattern | Example Column Names |
|------|---------------|----------------------|
| 1 | `^1[\.\s].*(?:before\|mark)` | "1. Before Photo", "1 Mark Position" |
| 2 | `^2[\.\s].*(?:during\|digging)` | "2. During Photo", "2 Digging In Progress" |
| 3 | `^3[\.\s].*(?:depth\|measuring)` | "3. Depth Photo", "3 Depth Measurement" |
| 4 | `^4[\.\s].*(?:end.?plate\|visible)` | "4. End Plates", "4 Visible Plates" |
| 5 | `^5[\.\s].*(?:compact\|backfill)` | "5. Compaction", "5 Backfill Photo" |
| 6 | `^6[\.\s].*(?:level\|spirit)` | "6. Level Check", "6 Spirit Level" |
| 7 | `^7[\.\s].*(?:after\|picture)` | "7. After Photo", "7 Picture Final" |
| 8 | `^8[\.\s].*(?:label\|foto\|photo)` | "8. Pole Label", "8 Photo Label" |

### Optical Dome Steps
| Step | Regex Pattern | Example |
|------|---------------|---------|
| 1 | `^1[\.\s].*dome.*pole` | "1. Dome on Pole" |
| 2 | `^2[\.\s].*dome.*label` | "2. Dome Label" |
| 3 | `^3[\.\s].*open.*dome` | "3. Open Dome" |
| 4 | `^4[\.\s].*splice.*protect` | "4. Splice Protectors" |
| 5 | `^5[\.\s].*slack.*manage` | "5. Slack Management" |
| 6 | `^6[\.\s].*strength.*member` | "6. Strength Members" |
| 7 | `^7[\.\s].*seal.*dust` | "7. Seals & Dust Caps" |
| 8 | `^8[\.\s].*pole.*id` | "8. Pole ID" |

## Deployment Notes

### Prerequisites
- PostgreSQL migration 231 must be applied
- QFieldCloud API token configured in `.env.local`
- MinIO containers accessible from application server
- Docker bridge network functioning (for qfieldcloud-* containers)

### Cron Setup
Add to `/etc/crontab` or via `crontab -e`:
```bash
0 3 * * * /home/velo/fibreflow-production/scripts/cron-qa-ingest.sh >> /tmp/qa-ingest-cron.log 2>&1
```

### Testing
```bash
# Test GPKG extraction (dry run)
python3 scripts/extract-gpkg-photos.py --project "Lawley" --dry-run

# Test push-qfield-comment (make manual request)
curl -X POST http://localhost:3000/api/construction-qa/push-qfield-comment \
  -H "Content-Type: application/json" \
  -d '{"reviewId":"<uuid>"}'
```

### Monitoring
- **Cron logs:** `/tmp/qa-ingest-cron.log`
- **Application logs:** Search for module tag `cqa-qfield-push` or `construction-qa`
- **Database:** Query `qfield_gpkg_sync_state` to see last sync status
