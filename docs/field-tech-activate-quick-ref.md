# Field Tech Quick Reference: Activate Module

**Version:** 1.0  
**Last Updated:** 2026-02-19  
**Target Audience:** Field technicians performing activation work

---

## 🔧 Quick Start: Submitting Activation Work

### 1. Access the Field App Portal
- Open your mobile browser to the Field App Portal URL (provided by your supervisor)
- Login with your FibreFlow credentials
- Review assigned tasks for the day

### 2. Start a Task
- Navigate to your assigned task using GPS coordinates
- Tap **"In Progress"** to start tracking your work
- Note: Work offline if needed — data will sync when you reconnect

### 3. Complete the Work
- Take **verification photos** of:
  - ONT installation
  - Cable routing
  - Customer premises ready state
  - Any issues encountered
- Add **notes** about work performed or problems found
- Record **equipment used** (ONT serial, router serial, cable lengths)

### 4. Submit the DR (Daily Report)
- Mark task as **"Completed"** (if successful) or **"Failed"** (with reason)
- Ensure all photos and notes are attached
- Submit — data will sync immediately if online

---

## 📸 Photo Upload Guidelines

### Required Photos
1. **ONT Installation** — clear view of device, mounting, connections
2. **Cable Entry** — showing proper routing and protection
3. **Equipment Placement** — router, UPS (if applicable)
4. **Customer Handoff** — signed form or acceptance proof

### Best Practices
- Use good lighting
- Keep lens clean
- Include reference objects for scale
- Capture any damage or pre-existing issues

### Offline Mode
- Photos are stored locally on your device
- They will auto-upload when you reconnect
- Check the sync indicator before leaving the site

## ✅ Checking Status of Your Submissions

### Via QA Centre
**Path:** Sidebar → Activate → QA Centre

**What you see:**
- List of all your submitted DRs
- Status for each: **Pending**, **Passed**, **Failed**, **Rework**
- Feedback from QA team if applicable

**Search & Filter:**
- Search by DR number
- Filter by status, project, or date range

### Via WhatsApp Monitor Dashboard
**Real-time tracking:**
- Daily submission count
- QA progress (passed/failed breakdown)
- Issues flagged for immediate attention

**Notifications:**
- Alerts for failed QA (with reason)
- Rework requests
- Urgent issues requiring follow-up

## 🚨 Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| **Can't sync data** | Check internet connection, retry sync button |
| **Photos won't upload** | Reduce photo size or wait for better signal |
| **Task not showing** | Contact supervisor — may need reassignment |
| **QA failed my DR** | Check QA Centre for feedback, fix issue, resubmit |
| **Equipment serial scan failed** | Manually enter serial number, verify accuracy |
