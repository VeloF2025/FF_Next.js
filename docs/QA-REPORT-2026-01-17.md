## Bugs Found

### P2: Clients "Total Value" Shows "RNaN"

**Severity**: Medium (P2)
**Module**: Clients
**Page**: `/clients`
**Component**: Stats card showing "Total Value"

**Description**:
The "Total Value" statistic card displays "RNaN" instead of a properly formatted currency value.

**Expected**: `R 140,000,000` or similar formatted number
**Actual**: `RNaN`

**Root Cause**: JavaScript NaN (Not a Number) error, likely from:
- Null/undefined value being used in calculation
- String being used where number expected
- Missing data validation

**Reproduction**:
1. Navigate to `/clients`
2. Observe the "Total Value" stat card

**Suggested Fix**:
```typescript
// Add null check and default value
const totalValue = clients.reduce((sum, c) => sum + (c.value || 0), 0);
// Or use Number() with fallback
const totalValue = clients.reduce((sum, c) => sum + (Number(c.value) || 0), 0);
```
